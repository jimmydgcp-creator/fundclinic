【基金复诊台】照这几步来

—— 第 0 步最要紧，先别关那个终端窗口 ——

0、
如果你那个跑服务的窗口还开着，**先别关**，先截个图发我
（要看有没有报错，关了就没了）。

然后**刷新一下浏览器页面**，看最上面「最近的复盘记录」里有没有 519191。
有的话直接点「载入」——上次的结果大概率已经生成好了，没白跑。


1、换新包

重新下载我发你的 zip（文件名一样，是刚更新的），解压覆盖掉旧的文件夹。
上次那个包有个问题：服务端一旦出错，浏览器只会显示一句 Load failed，
什么都看不到。新包修好了，还会自动把已生成的结果捞回来。


2、装 Poppler（上次报告缺了「官方季报对账」那一栏，就是因为它）

打开「终端」，输入这一行，回车：

    brew install poppler

⚠️ 如果提示 command not found: brew —— 说明没装 Homebrew。
   别自己折腾，把这句发我，我给你另一个装法。

装完验证一下，终端里输入：

    pdftotext -v

能打印出版本号（类似 pdftotext version 24.x.x）就是装好了。


3、重启服务

把原来那个终端窗口关掉（或者点进去按 Control + C）。
然后重新双击「启动_基金复诊台.command」。

启动后窗口里那两行应该是：

    环境:   pdftotext ✓ 可用(官方 PDF 逐行对账已启用)
            Edge/Chrome ✓ 可用

第一行是 ✗ 的话，说明第 2 步没成功，回来告诉我。


4、重新跑一次

输入 519191 → 开始复盘 → 确认口径那张表 → 按此口径开跑。

这次会久一点（要做官方 PDF 对账 + 大模型写深度报告），
几分钟是正常的 **不要关窗口、不要刷新**，让它跑完。


5、如果又出现 Load failed

先别慌，也不一定要重跑：
   · 刷新页面 → 看「最近的复盘记录」→ 点「载入」
   · 新包会自动做这一步，页面会直接告诉你「连接中断，但结果已生成」

如果还是不行，把这两样发我：
   ① 跑服务那个终端窗口的**完整截图**（整个窗口，包括上面的报错）
   ② 文件夹里 _runs/_server-error.log 这个文件（有的话）

有这两样我才能定位到底哪一步断的。
