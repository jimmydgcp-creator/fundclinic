【基金复诊台】输入基金代码 → 自动出复盘报告 + 演示稿

先说一句：Windows 和 Mac 的启动文件不一样，别弄混。

  Windows  →  启动_基金复诊台.bat
  Mac      →  启动_基金复诊台.command

（.bat 是 Windows 专用的，Mac 上双击只会用文本编辑器打开它 —— 那不是出错，
  是文件类型不对。用错了就换成上面那个。）

—————

解压之后按这个顺序来：

1、解压
右键压缩包 → 全部解压缩（Mac 直接双击就行）
⚠️ 别在压缩包里直接双击，那样跑不起来

2、先看一眼文件夹里的「★先读我_怎么用.txt」
里面写了为什么做这个工具，还有完整步骤。下面只是简版。

3、装 Node.js（只做一次，5 分钟）
   Windows：https://nodejs.org 下 LTS 版，一路"下一步"装完
   Mac：    同上，下载 LTS 版的 .pkg，双击一路"继续"装完
   装完都不用做任何配置。已经装过的跳过。

4、双击启动文件
   Windows 双击：启动_基金复诊台.bat
   Mac     双击：启动_基金复诊台.command
   弹出的窗口别关（关了服务就停），等 2-3 秒浏览器会自动打开
   没自动打开的话，看窗口里打印的地址，手动访问

   Mac 如果提示"无法执行该文件"或"无法验证开发者"：
   打开"终端"，输入 chmod +x 加一个空格，把 .command 文件拖进终端，回车。
   之后双击就正常了。
   （也可以完全不用双击：终端里输入 cd 加空格、把文件夹拖进去、回车，
     然后 node server.mjs）

5、填一次自己的 API Key
去 platform.deepseek.com 免费申请，几分钟
粘到页面上就行，浏览器会记住，下次不用再填

6、输入 6 位基金代码（比如 519191）→ 点「开始复盘」
会先让你确认一张表（复盘哪一任经理、哪个区间），确认后开跑
大约 10 秒出结果，报告和演示稿都能直接下载

—————

两个提醒：

① 想让报告里有「官方季报逐行对账」那一栏，要先装 Poppler
     Windows（PowerShell 里）：  winget install oschwartz10612.Poppler
     Mac（终端里）：             brew install poppler
   不装也能跑，只是那一栏会是空的

② 没有 API Key 也能打开页面，但跑不出结果
   主题归类和深度报告都要大模型参与

如果是 iPad / 手机：完整功能跑不了（装不了 Node），
只能双击「基金复诊台_单文件版.html」，用 Safari 打开看效果。

所有数据都在你自己电脑上，跑出来的东西存在文件夹的 _runs/ 里。
跑不通的把那个窗口截图发我。
